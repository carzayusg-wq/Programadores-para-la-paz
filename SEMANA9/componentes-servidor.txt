Sistema operativo:
Es el software principal del computador. Administra los recursos del sistema y permite ejecutar aplicaciones como Node.js.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador y crear servidores web.

Aplicación server.js:
Es el archivo donde se encuentra el código del servidor. Define las rutas y respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación que utiliza el servidor para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre la actividad del servidor, errores y eventos importantes para monitoreo.
