La autenticación nos permite identificar a un usuario mediante un proceso como el login antes de acceder a ciertas funciones. El login ayuda a verificar que una persona tiene permiso para utilizar partes específicas de una aplicación. Algunas rutas deben estar protegidas porque pueden contener información privada o permitir cambios importantes dentro del sistema. La protección evita que usuarios no autorizados puedan modificar o consultar datos internos. No se deben publicar contraseñas, documentos personales, direcciones, teléfonos, tokens, claves API ni información sensible de la comunidad.
